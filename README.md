# Fret Cards

Guitar fretboard flashcards for the phone, based on a printed card deck.

Quiz modes:
- **Staff → fretboard**: a note on the treble staff; tap where you play it.
- **Fretboard → note**: a marked fret; pick the note name.
- **Find every note**: tap every spot of a note across all strings and octaves.
- **Same pitch**: tap every other spot with the exact same pitch.
- **Mix all**

Settings: instrument (guitar or 4-string bass guitar), fret range (Position I / 0–5 / 0–7 / 0–12), sharps and flats, sound (synthesized acoustic guitar, simple tone, or off).
Missed cards come back more often. Works offline once opened.

## Install on iPhone
Open the site in Safari → Share → **Add to Home Screen**.

Single static page (`index.html`), no build step.
